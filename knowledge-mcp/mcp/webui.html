Connect host service

  1. Download the host service and extract it on the computer running Docker. Python 3.10+ is required.
  2. Generate a pairing key below.
  3. From the extracted folder, run python host_agent.py install --url http://127.0.0.1:8080 on that computer and paste the key when prompted.
