            Backup and restore
            Download settings, indexing state, Qdrant indexes, synchronized documents and the host agent connection. Model downloads and external document folders are not included. Keep the archive private: it contains documents and access credentials.
            Wait for indexing and folder synchronization to finish. Search pauses while the backup is created. Restore replaces this instance's data and restarts the app; use the saved dashboard password afterwards.
